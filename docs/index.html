Powerful Capabilities

Bridge the gap between your LLM and your network's core.

Async SSH

Built on asyncssh for high-performance, non-blocking connections to your OpenWRT hardware.

Native UBUS

Direct integration with OpenWRT's microbus for structured network and wireless data.

Smart Logs

Retrieve and parse system logs dynamically to diagnose connectivity issues in seconds.

HITL Security

Human-in-the-Loop confirmation for sensitive commands like rebooting or configuration changes.

DHCP Discovery

Instantly map connected devices with parsed lease data including MAC, IP, and Hostnames.

FastMCP

Optimized with Anthropic's FastMCP framework for rapid agentic response and discovery.

Human-in-the-Loop is Built-in

Safety first. Sensitive operations like reboot or uci set automatically pause execution and request explicit human approval via the MCP client elicitation protocol.

Tool Name Description Parameters

Diagnosticping_from_router Test connectivity from the router to an external host. host (str), count (int, default: 4)

Quick Start

Installation 
git clone https://github.com/PiterPentester/openwrt_mcp.git
cd openwrt_mcp
uv sync
Configuration 
# Set your router credentials
export OPENWRT_HOST="192.168.1.1"
export OPENWRT_PASSWORD="your_password"
Claude Desktop Config 
{
  "mcpServers": {
    "openwrt": {
      "command": "uv",
      "args": ["run", "/path/to/openwrt_mcp/main.py"],
      "env": {
        "OPENWRT_HOST": "192.168.1.1",
        "OPENWRT_PASSWORD": "your_password"
      }
    }
  }
}
